# Mini Project report

Run `bash build.sh` with Tectonic installed. It creates `MiniProject_Report.pdf`.
The source also works with a standard LaTeX installation; run `pdflatex` twice.

Before submission, put the online demo URL in `\DemoURL` near the top of
`MiniProject_Report.tex`, then rebuild. The PDF currently marks the video as
pending. Do not reuse the Assignment 1 or Assignment 2 video links.

The figures are native game screenshots. They are not frames from a demo video.
The report describes the current three-chapter game and its cleaned source code.
Validation covers 789 story assertions, 5 viewport assertions, 2 Python palm tests,
and native full-story QA with camera startup and restart.
